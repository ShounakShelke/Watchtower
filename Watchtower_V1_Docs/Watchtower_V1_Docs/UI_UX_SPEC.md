# Watchtower UI/UX Specification

## Design direction

Reference: supplied monochrome editorial website screenshot.

Target:
- better than reference
- more functional
- more information-dense
- still minimal

## Palette

Use only:
- #000000
- #171717
- #6B6B6B
- #E5E5E5
- #FFFFFF

No colored accents.

## Typography

Use a pixel/display font for:
- large hero headings
- section labels
- system/status labels
- major numbers

Use a highly readable font for:
- body text
- task descriptions
- AI responses

Do not use the pixel font for long paragraphs.

## Background

Subtle grid lines are allowed.

Avoid visual noise.

## Home

Strong hierarchy:
1. daily state
2. calendar
3. priority
4. recommendation
5. project status
6. intelligence
7. reminders

## Agent

Terminal/control-room aesthetic:
- command prompt
- system status
- tool execution trace
- reasoning summary
- action buttons
- confirmation states

Do not expose hidden chain-of-thought.
Only show concise action/reason summaries.

## Interaction

Use:
- keyboard-friendly input
- Enter to submit
- clear command history
- loading states
- tool status
- confirmations
- undo where practical

## Mobile

Navigation should collapse cleanly.

The Agent input should remain easy to reach.

Cards should become vertical sections.

Do not make desktop UI simply shrink on mobile.
