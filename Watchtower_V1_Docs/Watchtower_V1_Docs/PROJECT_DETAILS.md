# Watchtower — Project Details

## Product

Watchtower is a single-user personal AI operating system.

Primary purpose:

> Know what matters. Decide what to do. Remember what happened.

## User

Primary user: Shounak

## Product goals

1. Centralize daily information.
2. Provide an intelligent daily dashboard.
3. Maintain persistent context.
4. Provide an agentic command terminal.
5. Dynamically prioritize work.
6. Track projects and progress.
7. Provide intelligent reminders.
8. Provide daily/weekly reviews.
9. Provide AI/ML and motorsport intelligence.
10. Work from phone without requiring the user's PC to be online.

## Core navigation

- Home
- Agent
- Tasks

- Knowledge
- Intelligence
- Analytics
- Focus
- Settings

## Deliberately excluded

- standalone Notes page
- Neo4j
- Redis
- local LLM
- multi-agent architecture
- enterprise multi-user complexity
- unnecessary microservices

## Product personality

Concise when executing.
Analytical when explaining.
Context-aware when planning.
Proactive when useful.
Never noisy.

## Core question

"What should I do now?"

## Design

Black / white / gray.
Pixel/display typography.
Minimal editorial grid.
Terminal-like agent.
No colorful accents.
No generic SaaS gradients.

## V1

The agent is the MVP.

Everything else should support:
- context
- planning
- action
- memory
- tracking
