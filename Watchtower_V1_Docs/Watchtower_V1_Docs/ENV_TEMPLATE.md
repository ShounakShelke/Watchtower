# Environment Variables

Create a local `.env.local` from the actual `.env.example` generated by the project.

Expected categories:

## Database

DATABASE_URL=

## Authentication

AUTH_SECRET=
AUTH_URL=

## AI

GEMINI_API_KEY=
GROQ_API_KEY=

## Google Calendar OAuth

GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
GOOGLE_REDIRECT_URI=

## News

NEWS_API_KEY=

## Optional notifications/email

EMAIL_PROVIDER_API_KEY=

## Production

NEXT_PUBLIC_APP_URL=

Never commit real values.
Never expose secret keys through NEXT_PUBLIC_* variables.
